# Codex 전역 지침

## 공통 지침 원본

- 작업을 시작하기 전에 `~/.claude/CLAUDE.md`를 읽고 전체 내용을 이 Codex 전역 지침의 일부로 적용한다. 요약된 일부 규칙만 적용하지 않는다.
- 사용자는 Claude와 Codex의 동작을 동일하게 유지하도록 요청했다. 원본에 설정된 작업 기록, 코드 스타일, 응답 방식, 완료 알림, Git 자동화 및 경로별 예외를 모두 따른다.
- 원본 파일을 읽을 수 없으면 해당 사실을 알린다. 알림이나 Git 설정을 추측하거나 이전에 기억한 값으로 실행하지 않는다.
- 프로젝트의 `AGENTS.md`와 사용자의 현재 요청도 함께 따르며, 상충하는 규칙은 지침 우선순위에 맞게 처리한다.

## Codex에서의 해석

- `TodoWrite`를 사용할 수 없으면 사용 가능한 계획 도구로 작업 단계를 관리한다. 계획 도구가 없으면 해당 작업 파일에 진행 상황을 기록한다. 한 번에 하나씩 단일 기능을 구현하는 규칙은 유지한다.
- `@CLAUDE.PJT.md`는 자동 가져오기 문법에 의존하지 않고 직접 읽는다. 공통 원본 옆의 `~/.claude/CLAUDE.PJT.md`가 있으면 읽고, 대상 프로젝트 루트의 `CLAUDE.PJT.md`도 있으면 읽는다. 없는 파일은 임의로 만들지 않는다.
- 타임스탬프 생성은 원본의 Python 명령을 따른다. `python`이 없고 `python3`만 있으면 같은 코드를 `python3`로 실행한다.

## 완료 자동화

- 원본의 순서대로 작업 파일을 완료 처리하고 요약한 뒤, 설정된 앱 알림을 보내고, Git 자동화를 수행한다.
- 알림 ON/OFF, 메시지 형식, 수신 대상, Git 모드와 경로 예외는 매번 원본의 현재 설정을 따른다. 이 파일에 별도 값을 중복 관리하지 않는다.
- 사용자는 원본에 따른 완료 알림과 Git 자동화를 허용했다. 이 범위의 실행에 대해 매번 재확인을 요구하지 않는다.
- 알림은 원본처럼 `curl`과 UTF-8 JSON으로 보낸다. 인증값은 로컬 원본에서 읽어 사용하고 응답, 로그, 작업 파일, TIL, 커밋에는 출력하거나 복사하지 않는다.
- Git에는 이번 작업의 변경만 포함한다. 기존 사용자 변경이나 관계없는 파일을 함께 커밋하지 않는다.
- 알림 서비스 하나가 실패해도 다른 활성 알림과 Git 단계는 계속한다. 실행 결과를 확인하고 실패를 성공으로 보고하지 않는다.
- 환경의 파일 쓰기·네트워크·승인 제한은 우회하지 않는다. 제한으로 수행하지 못한 단계는 명확히 보고한다.
